# THE ASHEN KNIGHT
### Medieval 3D Action-Adventure สำหรับ PlayStation 2 (สไตล์กล่องเกมปี 2005)

เกมต้นฉบับที่เขียนขึ้นใหม่ทั้งหมดสำหรับ PS2 — ตัวละครอัศวินสวมเกราะ ต่อสู้ด้วยดาบ
กับศัตรูถือดาบ ในโลกยุคกลางที่มืดหม่น ปราสาท สะพานหิน เมือง และท่าเรือ
เรนเดอร์ด้วย gsKit บนฮาร์ดแวร์ GS จริง วีดีโอ NTSC 640×448

---

## สิ่งที่ทำเสร็จ (ตามโจทย์ 4 ระบบ)

**1. ระบบตัวละครอัศวิน**
- เดิน / วิ่ง (R1) ด้วยอนิเมชันขา-แขนแบบคีย์เฟรมในโค้ด
- กลิ้งหลบ (O) พร้อมช่วงอมตะ (i-frames) และใช้ stamina
- ฟันดาบคอมโบ 2 จังหวะ (กด X ซ้ำเพื่อต่อคอมโบ) มีสแตมินาเป็นตัวจำกัด
- กระปุกยาฟื้นพลัง (Triangle) 3 กระปุก, หลอด HP + หลอด Stamina
- ตัวละครประกอบจากกล่องหลายสิบชิ้น: หมวกเหล็กมีหงอนแดง, เกราะไหล่แบบปีก, เกราะอกประกบเป็นสันกลาง (keel),
  ทาบาร์ดแดงขลิบทอง, ผ้าคลุม 3 ชิ้นพับเป็นรอย, สนับแขนทอง, ดาบมีสันมีดสว่าง

**2. ระบบฉาก 3D**
- โลกต่อเนื่อง 1 แมพ (~4096 หน่วย) 4 โซน: **THE COURTYARD / THE OLD BRIDGE / ASHEN TOWN / THE HARBOUR**
- ปราสาท + ประตูใหญ่พร้อมประตูกล (portcullis) และคบเพลิงสองข้าง
- สะพานหินข้ามน้ำ มีเชิงเทินและหอประตู
- เมืองยุคกลาง: บ้านทรง 3D หลังคาจั่ว หน้าต่างเรืองแสง ถนนหินกรวด
- ท่าเรือ: ท่าไม้ ลังสินค้า เรือที่มีเสากระโดง น้ำ
- เนินดิน กำแพง หอคอย รูปปั้นอัศวิน ต้นไม้/กองไฟ/กระถางไฟ (brazier) กระจายทั่วแมพ
- พื้นดินเป็น mesh 3D จริงพร้อม LOD 3 ระดับ (64/128/256) เพื่อลดจำนวน face

**3. ระบบต่อสู้**
- ศัตรูถือดาบ 9 ตัว ไล่ล่า โจมตีเป็นจังหวะ มีช่วง recover ให้ตอบโต้
- ล็อกเป้า (L1) กล้องหมุนตามเป้า มีเรติเคิลสีทอง
- หลอดเลือดศัตรูลอยเหนือหัว + บอส **THE WARDEN** มีหลอดเลือดกลางจอ
- ระบบฟันถูก/โดนฟัน, กระเด็น (knockback), ประกายไฟ (sparks), ตายแล้วกด START เพื่อเกิดใหม่

**4. ระบบบรรยากาศ**
- กลางคืน ท้องฟ้าดำไล่เฉดพร้อมดาวและพระจันทร์มี corona 3 ชั้น
- หมอกตามโซน (fog สีต่างกัน 4 โซน) + fog ตามระยะ
- แสงคบเพลิง: point light แบบ static สูงสุด ~28 ดวง + ไฟกะพริบ (flicker) + แสง dynamic ตามตัวละคร/ศัตรู
- เงานุ่มใต้ตัวละคร, billboard เปลวไฟ/เรืองแสง, เอฟเฟกต์ประกายไฟ
- **ชาวเมือง NPC 7 คน** เดินไปมาในเมือง/ท่าเรือ ถือตะเกียงที่ส่องไฟจริง (มี point light ติดตัว)
- ไฟคบเพลิงมี "แอ่งแสง" บนพื้นแยกจากเปลวไฟ ทำให้แสงติดพื้นไม่ลามเป็นแท่งขาว
- **เสียง: ยังไม่มี** — ดูหัวข้อข้อจำกัดด้านล่าง (ข้อนี้ผมไม่แต่งเติมให้ดูดีเกินจริง)

## เทคนิคกราฟิกที่ใช้ (รอบปรับปรุงล่าสุด)

เป้าหมายคือ "ภาพสวยที่สุดเท่าที่ PS2 ทำได้" ภายใต้งบของเครื่องจริง ทุกเทคนิคข้างล่างนี้
อยู่ในโค้ดเดียวกันทั้ง build PS2 และ preview บน PC

| เทคนิค | สิ่งที่ทำในเกม | ผลที่เห็น |
|---|---|---|
| **Texture Mapping + Atlas** | atlas 256×256 รวมวัสดุ 16 แบบ (หิน, หินกรวด, กระเบื้อง, ไม้, น้ำ 4 เฟรม, กระเบื้องหลังคา, ปูน, เหล็ก, ผ้า, ดิน, มอส, ทอง, ดำ) แต่ละ face เลือก cell + พลิก UV แบบสุ่มต่อ tile | ผนัง/ถนนมีลายจริง ไม่ต้องเพิ่มโพลิกอน |
| **Vertex Lighting (Gouraud)** | ใบหน้าแนวนอนขนาด >18 หน่วย (พื้นกระเบื้อง, ท่าเทียบเรือ) คำนวณแสงที่ vertex ทั้ง 4 มุม แล้วส่งต่อให้ GS interpolate ด้วย `gsKit_prim_quad_goraud_texture_3d` | หลุมแสงจากคบเพลิงไล่ระดับนุ่มแทนที่จะเป็นสี่เหลี่ยมแบน |
| **Fog + Atmospheric Perspective** | fog ตามระยะ (near/far) + สี fog แยก 4 โซน + haze band ที่เส้นขอบฟ้า | ฉากไกลจมหมอก ระยะใกล้-กลาง-ไกลอ่านออก |
| **Environment Reflection (จำลอง)** | Fresnel `(1-\|N·V\|)³` + ไฮไลต์สะท้อนพระจันทร์ `(R·M)⁸` บนวัสดุเหล็ก/ทอง/หินหลังคา และน้ำ (มี ripple มอดูเลตตามตำแหน่ง+เวลา) | เกราะ/ดาบเป็นโลหะมันวาว น้ำมีแสงจันทร์ระยิบ |
| **Sky Dome** | gradient 18 ชั้น + เมฆ 4 ชั้นลอยช้า ๆ + ดาว 80 ดวงกระพริบเบา ๆ + ฮาโลพระจันทร์ 4 ชั้น | ท้องฟ้ามีมิติ ไม่ใช่สีเรียบ |
| **LOD + Culling** | พื้นดิน 3 วง (64/128/256), prop LOD ตามระยะ, actor LOD ที่ 620 หน่วย, ตัด face นอกจอ/ใกล้กล้องเกิน | คุมที่ ~1,200–3,000 face/เฟรม |
| **Particle Effects** | 3 ชนิด: ประกายดาบ, เถ้าลอยจากกองไฟ (ลอยขึ้น+ดับ), ฝุ่นใต้เท้า/ตอนกลิ้ง (ขนาดขยายแล้วจาง) รวมสูงสุด 120 ตัว | ฉากมีชีวิต |
| **Painter's Algorithm** | เรียง face ไกล→ใกล้ (counting sort 1024 ถัง) แล้วปิด z-test | เลียนแบบ pipeline เกม PS2 ยุคนั้น |

> หมายเหตุตามจริง: environment mapping ที่ทำเป็นการ **จำลองเชิงสี** ไม่ใช่ cube map จริง
> (GS ไม่มีฟังก์ชันนั้นในเส้นทางที่เราใช้) และไม่ได้ใช้ pre-rendered background เพราะเกม
> กล้องหมุนอิสระทั้งฉาก

## รอบปรับลุค "ตัวละครและ NPC" (ล่าสุด)

ปรับตามคอมเมนต์ว่าตัวละครและ NPC ยังดูไม่น่าเล่น:

- **อัศวิน/ศัตรู**: เกราะอกสร้างใหม่จากแผ่นประกบสองชิ้นบรรจบสันกลาง + แผ่นข้าง + แผ่นหลัง
  แทนกล่องแบน; เกราะไหล่ทำเป็นปีกเอียงรับแสงแยกจากลำตัว; หมวกมีโหนก, ครอบแก้ม,
  หน้ากากร่องรูป T, หงอนและปีกข้าง; ผ้าคลุมแยกเป็น 3 แผ่น (กลางนูน ปีกโค้งเข้าหาตัว)
  พร้อมชายผ้าสีเข้ม จึงเห็นรอยพับและน้ำหนักแสงแทนการ์ดแบนแผ่นเดียว
- **ลดแสงจนเกราะไม่ขาววับ**: ลด specular env, ลดแสงสะท้อนจากกล้อง, ลดคีย์ไลท์ผู้เล่น
  และศัตรู ทำให้เหล็กออกเป็นสีเทาเหล็กที่ยังมีไฮไลท์ ไม่ใช่กล่องขาว
- **ชาวเมือง**: โมเดลใหม่ทั้งตัว (ขาแกว่งตามก้าว, เสื้อคลุม 3 ชั้น, เข็มขัด, ฮู้ดมีชายข้าง,
  ใบหน้า/ตา, ตะเกียงเหล็กติดมือที่มีเปลวไฟ + แสงจริง) ใส่สีเสื้อต่างกัน 3 โทน
- **คบเพลิง/ตะเกียง**: เปลวไฟมีขนาดจำกัดตามระยะ (ไม่บวมเป็นแผ่นขาวเมื่อเดินประชิด),
  เพิ่มแอ่งแสงแบนบนพื้น, ลดความแรงไฟ static ที่หัวคบเพลิง
- **พื้นหิน**: ลดความสว่างกระเบื้อง/หินกรวดลงและเพิ่มความต่างของแต่ละ tile
  ผนังหินจึงเด่นขึ้นและฉากไม่ดูเป็นปูนขาว
- **พระจันทร์**: เปลี่ยนจากสี่เหลี่ยมเป็นดวงกลมไล่เฉด พร้อมฮาโลนุ่ม
- **HUD**: ป้าย "VIALS X 3" อ่านชัด (atlas 128×64 ยกกำลังสอง)

## วิธีเล่น

### บน PCSX2 (แนะนำสำหรับทดลองเร็ว)
1. เปิด PCSX2 → `System ▸ Boot ISO` แล้วเลือก `ashen-knight.iso`
   (หรือ `System ▸ Boot ELF` แล้วเลือก `ASHEN.ELF` ก็ได้)
2. ตั้งค่า BIOS เครื่อง NTSC (ค่าเริ่มต้นส่วนใหญ่ใช้ได้)
3. ถ้าภาพขึ้นจอดำแต่เสียง/เครื่องเดินอยู่ ให้รอ 2–3 วินาทีแรก (เกมมีลำดับ boot)

### บน PS2 เครื่องจริง
- **FMCB + OPL ผ่าน USB**: คัดลอก `ashen-knight.iso` ลงโฟลเดอร์ `DVD` ในแฟลชไดรฟ์ USB
  แล้วเปิดด้วย OPL (โหมด ISO)
- **แผ่น**: เขียน `ashen-knight.iso` ลง DVD-R ด้วยโปรแกรมเขียน ISO ทั่วไป
  (แผ่นเกม PS2 ต้องใช้ DVD-R + วิธี boot ที่เครื่องรองรับ)
- ตัวเลือก: วาง `ASHEN.ELF` ไว้บน `mass:/` แล้วรันผ่าน uLaunchELF ก็ได้

### อาการที่อาจเจอ
- จอแรกจะเปลี่ยนสีสั้น ๆ (navy → purple → black) เป็นขั้นตอน boot ตามปกติ
- ถ้าแพดไม่ตอบสนองในช่วงแรก เกมจะลองโหลด SIO2MAN/PADMAN ซ้ำให้เองหลายรอบ

## บิลด์จากซอร์ส

ต้องมี PS2DEV toolchain (ee-gcc + ps2sdk + gsKit):

```bash
export PS2DEV=/path/to/ps2dev/ps2dev
export PS2SDK=$PS2DEV/ps2sdk
export GSKIT=$PS2DEV/gsKit
export PATH=$PS2DEV/ee/bin:$PS2DEV/bin:$PS2SDK/bin:$PATH

make                 # -> ashen-knight.elf
mips64r5900el-ps2-elf-strip --strip-all ashen-knight.elf -o ASHEN.ELF
mkdir -p dist_iso && cp ASHEN.ELF SYSTEM.CNF dist_iso/
genisoimage -iso-level 1 -sysid PLAYSTATION -V ASHENKNIGHT -no-pad \
            -o ashen-knight.iso dist_iso
```

### โครงสร้างโค้ด
```
src/game.h        สัญญากลาง (ชนิดข้อมูล, plat_* API, ค่าคงที่)
src/game.c        ลูปเกม, กล้อง, ตัวละครผู้เล่น, HUD, ท้องฟ้า, ไฟ dynamic
src/world.c       สร้างโลก, prop ทุกชนิด, แสง static/dynamic, หมอกตามโซน
src/actors.c      โมเดลอัศวิน/ศัตรู, อนิเมชัน, เอฟเฟกต์
src/mesh.c        face list, transform, vertex/flat lighting, env term, painter sort
src/font.c        ฟอนต์ 5×7 ที่สร้างเป็น texture strip
src/materials_data.c  atlas 256×256 (16 วัสดุ) อบมาในไบนารี
src/ps2_main.c    backend ของ PS2: gsKit, DMA, แพด, boot
tools/preview_host.c  backend สำหรับ PC (software rasteriser) ใช้ทำ look-dev
```

### เกี่ยวกับการเรนเดอร์
GS ของ PS2 ไม่มี Z-buffer ที่ใช้ได้จริงกับฉากแบบนี้ เกมจึงใช้**Painter's Algorithm**
แบบเดียวกับเกม PS2 ยุคนั้น: ทุก face ถูกแปลงเป็นพิกัดจอ, ตัดทิ้งนอกจอ, แล้วเรียงจากไกลไปใกล้
(radix/counting sort 1024 ถัง) ก่อนส่งให้ GS โดยปิด z-test — ทำให้ได้ภาพแบบ "ยุค 2005" ตามที่ต้องการ
และคุมงบได้ที่ ~2,200–3,000 face ต่อเฟรม (เพดาน 3,400; ใช้ gsKit oneshot queue 4 MB)

### เครื่องมือทำภาพ (ไม่ต้องมี PS2)
```bash
make -f Makefile.preview            # -> ./preview (ใช้ gcc ปกติ)
./preview shots/courtyard.ppm courtyard
./preview shots/bridge.ppm    bridge
./preview shots/town.ppm      town
./preview shots/harbour.ppm   harbour
./preview shots/gate.ppm      gate
./preview shots/fight.ppm     fight
./preview shots/title.ppm     title
./preview shots/portrait.ppm  portrait   # ภาพโคลสอัพอัศวิน
./preview shots/folk.ppm      folk       # ชาวเมือง + ตะเกียง
./preview shots/horde.ppm     horde      # ศัตรู 4 ตัวประชิด
```
เรนเดอร์ฉากเดียวกันด้วย rasteriser บน PC ออกเป็น PPM เพื่อตรวจงานภาพก่อนขึ้นเครื่อง

## ข้อจำกัด (ตามจริง)

1. **ยังไม่มีเสียง** — โจทย์ข้อ 4 ระบุ "เสียงประกอบ"; ผมทำแสง/หมอก/ท้องฟ้าเสร็จ
   แต่ยังไม่ได้ต่อ audsrv + คลังเสียง ADPCM จึงยังเงียบอยู่ ถ้าต้องการ ผมทำต่อได้
2. **Painter's algorithm** มีอาการ face ซ้อนผิดลำดับได้ในมุมกล้องแปลก ๆ (เป็นข้อจำกัดของเทคนิคนี้)
3. โค้ด backend ของ PS2 (`ps2_main.c`: gsKit, DMA, แพด) **คอมไพล์และแพ็กเป็น ISO สำเร็จ**
   แต่ในสภาพแวดล้อมนี้ไม่มีเครื่อง PS2/PCSX2 ให้รันจริง ภาพที่แนบมาจาก backend บน PC
   ที่ใช้โค้ดฉาก/แสง/กล้องชุดเดียวกัน — จึงยังไม่ได้ยืนยันบนฮาร์ดแวร์จริง
4. ความละเอียด 640×448 NTSC, ไม่มีตัวเลือก video mode อื่น
5. เนื้อหาเป็น demo โลกเดียว ไม่มีระบบเซฟ/โหลด
